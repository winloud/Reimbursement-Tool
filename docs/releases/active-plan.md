# 当前开发计划

## 状态
- 版本号：v1.3.0
- 计划状态：开发中
- 预计版本类型：minor

## 目标
- [x] 支持从铁路电子客票 PDF 批量生成行程并关联车船费发票。
- [x] 识别同日或次日的连续站点并默认合并，明显返程或路线回环自动拆分。
- [x] 文件选择顺序混乱时，按日期和精确站点连接自动整理无歧义路线链。
- [x] UI：行程卡日期/地点输入框按卡片宽度自适应，已上传发票改为紧凑双列列表，所有数字输入框隐藏原生上下微调箭头。
- [x] UI：铁路电子客票导入区支持拖入、Ctrl+V 粘贴和选择 PDF，并复用发票上传区的焦点、拖入和接收反馈。
- [x] 其他费用项改动：燃油补助中，当我删除发票时，不要清空报销金额。当发票金额小于报销金额时，允许保存和预览，但不允许标记为已打印。提醒用户发票金额不足，补充足额发票后才能打印。
- [ ] UI：报销单录入的费用汇总卡片改动：1. 分为车船费、途中补贴、其他费用、汇总 4大块， 2.其他费用为￥0项，不要显示
- [ ] feat: 所有费用类别增加纸质发票填报入口，可手动添加发票金额和张数，不用考虑纸质发票的上传和保存。
- [ ] feat: 需要适配短时外出不足以领取1天的途中补贴的情形。我不希望通过时间来判断，是否允许用户直接修改出差总天数和总补贴金额？
- [ ] feat: 上传重复发票预警
- [ ] 发票信息确认窗口打开原始文件按钮，可调用本地默认PDF浏览器。（适用本地版，服务器版仍保留浏览器打开）

## 范围
本次做：
- 燃油补助手填报销金额与已确认发票金额分离；发票不足时保留金额并允许保存、预览。
- 发票不足时禁止单张/批量 PDF 下载及状态标记为已打印；已打印单据因删票或调低发票变为不足时自动退回草稿。
- 报销单行程区增加多张铁路电子客票导入入口。
- 车票解析预览、字段修正、排序、中转候选提示和事务化确认导入。
- 按 PDF 字体 CMap 解码中文站名，不使用 OCR 或英文站名回退。
- 不读取车票时间；同日或次日的连续站点默认合并，明显返程或路线回环在返程票前拆分。
- 多文件选择顺序混乱时，先按乘车日期和精确站点连接关系整理唯一路线链；分叉、多前驱和循环保持保守处理。
- 一段简化行程关联多张原始车票，金额继续逐票确认并汇总。
- 补充解析、中转、重复检测、事务和前端交互测试。

本次不做：
- 不查询 12306 或第三方列车时刻服务。
- 不修改行程数据结构，不持久化时间、车次、席别和座位。
- 第一阶段不支持图片车票。
- 未明确版本号和发布前验证前，不主动同步或部署 Linux 服务器；后续修改先在本地完成测试。

## 完成记录

### 重要改动
- 燃油补助手填报销金额不再随删除、调低或取消确认发票而被静默截断；留空金额仍按已确认发票合计动态计算。
- 燃油补助发票不足会在费用卡和汇总区提示缺口，可继续保存和预览；单张下载、批量下载和标记为已打印统一拒绝并提示补充足额发票。
- 已打印报销单因编辑燃油补助金额、删除或调低燃油补助发票而出现不足时，自动创建安全快照并退回草稿；快照失败则取消该次修改。
- 新增铁路电子客票 PDF 批量解析预览、字段修正、排序、拆分和事务化导入。
- 铁路票中文改为按字体 `/Encoding` 或 `/ToUnicode` 解码内容流原始字节，不使用 OCR 或英文站名回退。
- 站名主体与末尾“站”分属相邻文字运行时，按内容顺序、基线和页面坐标保守拼接，兼容字体和 Form XObject 缩放差异。
- 中转改为同日或次日连续站点默认合并；到达已访问站点的明显返程或路线回环在该票前拆分。
- 车票首次预览改为先自动整理无歧义路线链，再执行中转分组；文件名或选择顺序不再决定正常路线链的先后，进入预览后仍可人工移动。
- 简化后的中转行程可关联多张未确认车船费发票，并复用现有逐张确认与金额汇总流程。
- 临时预览使用两小时令牌；导入、失败、取消和返回重选都会清理对应临时文件。
- 预览批次内单个损坏或非铁路电子客票 PDF 改为跳过并在预览中提示，不再中止整批解析；令牌目录若在准备阶段异常也会清理，不残留孤立临时目录。
- 预览确认界面可删除单张车票（例如重复项），导入端改为按预览车票子集校验，允许仅导入用户保留的车票。
- 预览响应不再下发后端分组结果，分组统一由前端按用户实时交互计算，避免每次上传重复计算和无用负载。
- 行程卡的出发/到达面板改为按可用宽度自动并排或换行；月、日、时使用三个等分列并保留两位数字最小宽度，地点独占完整第二行。
- 已上传发票列表改为固定双列的紧凑卡片：将金额、类型和确认状态合并为统一文字基线的一行，进一步压缩高度，同时保留查看和删除操作；长发票号以省略号显示并可悬停查看完整内容。
- 所有数字输入框移除浏览器原生上下微调箭头，金额仍保留两位小数的直接输入和原有校验。
- 高铁车票导入区改为与发票上传区一致的交互：可拖入、Ctrl+V 粘贴或选择多个 PDF，焦点、拖入和文件接收时均有统一高亮反馈；剪贴板中没有文件名的 PDF 会自动补充 `.pdf` 后缀供后端解析。
