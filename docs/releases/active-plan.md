# 当前开发计划

> 只记录当前目标、范围、验收条件和阻塞；完成结果、长期验证和技术决策分别写入 `CHANGELOG.md`、`docs/testing/`、`docs/decisions/`。正式发布前冻结本文件。

## 状态

- 版本号：v1.4.0
- 计划状态：主体实现完成，待实物打印验收
- 预计版本类型：minor

## 目标

- [x] 新增与出差报销相互独立的常规报销单，支持无票报销和有票报销两种创建后不可切换的模式。
- [x] 常规报销沿用现有状态、附件、发票确认和本地数据安全能力，并使用独立列表、PDF 模板分派和字段映射。
- [ ] 扫描正式空白表单，完成矢量重绘、毫米坐标校准和 100% 比例实物打印验收。

## 范围

- 本轮包含：常规报销数据结构与兼容迁移、逐项目凭据/发票、独立列表与汇总卡、一级侧栏导航、PDF 字段映射和模板分派。
- 无票模式按项目录入日期、名称和金额，凭据支持 PDF/图片且不作为提交门槛；单据张数按附件页数统计。
- 有票模式按项目上传并确认发票，金额取已确认发票合计，单据张数按发票记录统计。
- 常规报销不包含部门、出差事由、行程、补贴、预支和差旅看板统计。
- 正式扫描件到位前完成可独立验证的数据、接口、界面和 PDF 逻辑链路；最终模板重绘与实物打印验收后补。
- 本轮不包含：未经用户明确授权，不主动同步或部署 Linux 服务器，也不执行远端发布。

## 验收条件

- [x] 历史数据迁移后全部保持为差旅报销，既有差旅录入、统计、PDF、导入导出和状态行为不变。
- [x] 两种常规模式均可完成新增、编辑、自动保存、状态流转、只读、回收站、筛选、批量操作和数据导入导出。
- [x] 无票凭据按项目归属并正确统计 PDF 页数/图片数；有票发票按项目归属并执行确认与全库查重。
- [x] 侧栏保持一级菜单，在“出差报销单”和“常规报销单”之间显示分隔；常规列表上方显示四张汇总卡且不建设看板。
- [x] 常规 PDF 按类型分派、每页四项、仅末页合计，并按项目顺序合并附件；缺少正式模板时返回明确阻塞提示。
- [x] 数据结构升级兼容旧版本导入，专项测试、前端构建和 `scripts/verify.ps1 -Profile All` 通过。
- [ ] 正式扫描件到位后，渲染对照、签章留白和 100% 比例实物打印通过。

## 阻塞

- 正式空白扫描件及其物理尺寸尚未提供；常规 PDF 模板重绘、坐标校准、视觉对照和 100% 比例打印验收暂时阻塞。
