# 当前开发计划

> 只记录当前目标、范围、验收条件和阻塞；完成结果、长期验证和技术决策分别写入 `CHANGELOG.md`、`docs/testing/`、`docs/decisions/`。正式发布前冻结本文件。

## 状态

- 版本号：v1.4.1
- 计划状态：开发中
- 预计版本类型：patch

## 目标

- [ ] 收紧其他费用的添加入口，并让自定义费用支持手动指定报销金额。
- [ ] 保持编辑报销单时新增内容直接展开，减少新增后的二次点击。
- [ ] 删除行程、其他费用项或常规报销项时，自动清理其关联发票与凭据。

## 范围

- 本轮包含：其他费用添加菜单隐藏“行李费”和“未乘卧铺补助”；移除“自定义费用”前置加号；自定义费用沿用燃油补助的手动报销金额、发票缺口和输出逻辑；新增行程、其他费用项、常规报销项后直接展开编辑区；删除行程、其他费用项、常规报销项时级联软删除关联电子发票和凭据，并清空随父项保存的纸质票据。
- 本轮不包含：改变固定 PDF 行；调整数据结构版本；发布、打包或部署。

## 验收条件

- [ ] “添加费用”菜单不显示“行李费”和“未乘卧铺补助”，历史报销单中的这两类费用仍可正常显示。
- [ ] 自定义费用菜单项不显示前置加号；可留空按已确认发票合计，也可手动指定报销金额，并在票额不足时阻止提交或下载。
- [ ] 编辑报销单时，新增行程、其他费用项、常规报销项后对应编辑区立即展开。
- [ ] 行程、其他费用项和常规报销项即使已有发票或凭据也可直接删除，删除后不残留有效关联文件或金额。
- [ ] 相关前后端定向测试、前端构建和差异检查通过。

## 阻塞

- 无。
