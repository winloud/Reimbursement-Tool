## 完成记录

### 重要改动
- 新增铁路电子客票 PDF 批量解析预览、字段修正、排序、拆分和事务化导入。
- 铁路票中文改为按字体 `/Encoding` 或 `/ToUnicode` 解码内容流原始字节，不使用 OCR 或英文站名回退。
- 站名主体与末尾“站”分属相邻文字运行时，按内容顺序、基线和页面坐标保守拼接，兼容字体和 Form XObject 缩放差异。
- 中转改为同日或次日连续站点默认合并；到达已访问站点的明显返程或路线回环在该票前拆分。
- 车票首次预览改为先自动整理无歧义路线链，再执行中转分组；文件名或选择顺序不再决定正常路线链的先后，进入预览后仍可人工移动。
- 简化后的中转行程可关联多张未确认车船费发票，并复用现有逐张确认与金额汇总流程。
- 临时预览使用两小时令牌；导入、失败、取消和返回重选都会清理对应临时文件。
- 预览批次内单个损坏或非铁路电子客票 PDF 改为跳过并在预览中提示，不再中止整批解析；令牌目录若在准备阶段异常也会清理，不残留孤立临时目录。
- 预览确认界面可删除单张车票（例如重复项），导入端改为按预览车票子集校验，允许仅导入用户保留的车票。
- 预览响应不再下发后端分组结果，分组统一由前端按用户实时交互计算，避免每次上传重复计算和无用负载。
