# 当前开发计划

> 只记录当前目标、范围、验收条件和阻塞；完成结果、长期验证和技术决策分别写入 `CHANGELOG.md`、`docs/testing/`、`docs/decisions/`。正式发布前冻结本文件。

## 状态

- 版本号：v1.3.1
- 计划状态：进行中
- 预计版本类型：patch

## 目标

- 让批量报销单状态操作支持跨状态更新，同时保证草稿离开流程前的数据完整性。

## 范围

- 本轮包含：批量状态的逐条跨状态更新与结果反馈；草稿离开时的出差事由和燃油补助发票校验；已核对、已提交、已报销的只读边界；PDF 下载校验保持；报销单列表的批量状态入口与稳定选中体验。
- 本轮不包含：单条状态跳级、正式发布、远端同步或 Linux 部署。

## 验收条件

- 批量操作可把每张有效报销单直接改为任一不同状态；单条失败仅跳过并说明原因，回退仍创建安全快照。
- 草稿直达已核对、已提交或已报销均要求出差事由非空且燃油补助发票足额；已核对、已提交和已报销互转不重复执行该完整性校验。
- 单条状态控件和后端接口继续只允许相邻流转；草稿到已核对使用同一套完整性校验。
- 只有草稿可修改报销单内容、发票和车票；回退草稿后恢复编辑。
- PDF 预览仍允许燃油补助发票不足；单张下载和批量下载继续保留既有燃油补助发票校验。
- 勾选报销单后，页面右上角固定按钮区切换为批量操作态；筛选区、表头和数据行坐标保持不变，并保持复选框焦点。
- 后端和前端相关测试通过，`scripts/verify.ps1 -Profile All` 通过。

## 阻塞

- 无。
