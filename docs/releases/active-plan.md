## 目标

- [x] 为每张报销单增加一个报销单级非发票附件区域，支持 PDF 和图片，并在导出时追加到全部发票之后。
- [x] 固化报销 PDF 的附件顺序：先按行程、再按其他费用项目，项目内保持上传顺序。

## 范围

- 本轮包含：报销单级附件模型与接口、其他费用之后的单一紧凑上传区、基本信息与非发票附件的外置区块标题、与既有发票上传区一致的聚焦/拖入/接收反馈、附件查看和删除、PDF 合并排序、图片原尺寸转 PDF、附件筛选、完整数据 ZIP、备份恢复和彻底删除兼容。
- 本轮不包含：附件金额或数量统计、发票识别与查重、附件手动排序、PDF 页面预览合并、状态机调整、版本号调整、发布或部署。

## 验收条件

- [x] 每张报销单只显示一个“非发票附件”区域，位于整个其他费用区域之后；“基本信息”和“非发票附件”的标题位于内容卡片外并与“行程列表”同层级；草稿可上传和删除，只读状态仅可查看。
- [x] 非发票附件上传区的聚焦、拖入、粘贴接收反馈与既有发票上传区保持一致。
- [x] 非发票附件不改变发票数量、金额、确认状态或发票筛选，且“有附件”筛选可识别电子发票或非发票附件。
- [x] 导出顺序稳定为报销单、行程发票、其他费用发票、非发票附件；行程和项目内按上传顺序，其他费用项目按页面顺序。
- [x] PDF 附件保留原页面，图片不做主动缩放或压缩并按原像素宽高生成页面；单张和批量下载行为一致。
- [x] 数据结构迁移、完整数据 ZIP、备份恢复、完整性检查和彻底删除覆盖非发票附件；自动化验证、生产构建和真实页面验收通过。
