## 目标

- [x] 多页发票按现有发票号识别结果和原始页序建立连续分组，避免同一张多页发票被误判为重复。
- [x] 无法明确分组时保留完整 PDF 作为待人工确认发票，并提供拆分提醒。
- [x] 多页发票仍作为一份发票记录管理，但统计和 PDF 单据张数按实际页数累计。

## 范围

- 本轮包含：多页普通发票的连续分组、保守回退、上传提醒、最后一页重新解析依据、电子发票实际页数统计，以及对应后端和前端测试。
- 本轮不包含：新增 OCR、版式或相似度识别算法；改变金额选择规则；改变铁路电子客票导入流程；发布、打包或远端部署。

## 验收条件

- [x] 连续同号页面合并为一条记录；单一分组保留原始 PDF，多分组子 PDF 保持原始页序。
- [x] 同号页面不连续或任一页缺少发票号时，完整 PDF 只创建一条未确认记录，并返回对应提醒。
- [x] 整文件、明确分组文件和全库发票号查重继续生效，失败时数据库与附件回滚。
- [x] 提醒不计入失败或重复，上传结果对话框保留继续确认入口。
- [x] 已保存的多页发票重新解析使用最后一页，铁路电子客票导入流程不变。
- [x] 一份四页发票在上传列表中显示为一份，在报销单、行程、费用项目和 PDF 统计中计为四页。
