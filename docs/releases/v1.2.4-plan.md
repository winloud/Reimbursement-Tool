# v1.2.4 发布计划

## 状态
- 版本号：v1.2.4
- 计划状态：发布准备中
- 预计版本类型：minor

## 目标
- [x] 完成前端 UI 第一轮低风险打磨，让现有页面更像本地报销工作台。
- [x] 改进发票上传交互，增强拖拽反馈并支持 Ctrl+V 粘贴上传。

## 范围
本次做：
- 统一前端 MUI 主题中的卡片、按钮、表格、输入框、状态色和数字显示风格。
- 优化总览看板、报销单管理、报销单录入、个性化设置和数据维护页的视觉一致性。
- 强化报销单录入页的页面内导航、行程标题、发票确认状态和 PDF 阻塞提示。
- 让报销单管理列表批量操作条保持可见；发票确认状态回到详情页处理，不在列表增加低价值状态列。
- 改进发票上传区的选中状态、拖拽目标反馈、落位动画和上传中状态。
- 支持在目标费用上传区粘贴剪贴板中的 PDF 或图片，并沿用现有保存、批量上传和确认流程。

本次不做：
- 未明确版本号和发布前验证前，不主动同步或部署 Linux 服务器；后续修改先在本地完成测试。
- 不新增后端 API，不改变数据库结构。
- 不恢复已删除的 UI 参考或预览 HTML 文件。

## 版本号判断
- 如果只是修复问题：patch
- 如果增加用户可见功能：minor
- 如果数据结构或使用方式有不兼容变化：major

## 完成记录

### 重要改动
- 前端全局主题调整为更稳的报销工作台风格，统一卡片边框、按钮、输入框、表头、状态色和金额数字显示。
- 总览看板 summary 卡片增加状态色边和悬停反馈，费用分布改为类别排行/占比条。
- 总览看板的 Grid 容器收窄到页面宽度内，修复真实数据下 390px 窄屏轻微横向溢出。
- 报销单管理列表的批量操作条改为 sticky；取消“发票/附件”列表列，避免所有报销单都显示“详情内确认”的低价值提示。
- 报销单录入页新增页面内锚点导航；行程卡片标题直接显示路线和发票状态；费用汇总卡提前提示未确认发票会阻止 PDF 预览/下载。
- 发票上传区移除装饰图标，降低默认视觉重量；点击或键盘选中后切换为浅蓝底和实线边框，并继续保留拖入目标与落位动画反馈。
- 发票上传区可聚焦并支持 Ctrl+V 粘贴 PDF 或图片；剪贴板截图缺少文件名时自动补充后端可识别的扩展名。
- 个性化设置和数据维护页复用统一卡片、分区图标和软面板样式。
