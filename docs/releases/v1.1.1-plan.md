# v1.1.1 发布计划

## 状态
- 版本号：v1.1.1
- 计划状态：已发布
- 预计版本类型：patch

## 目标
[x] 独立服务重启脚本，避免AI每次浪费token重写脚本重启前后端。
[x] ZIP 文件名规则是 报销管理-vX.Y.Z-yyyymmdd ，同步到发布脚本。
[x] GitHub Release 自动读取 `CHANGELOG.md` 对应版本段落作为 release notes。

## 范围
本次做：
- 修复与打磨 v1.1.0 后的燃油补助、行程日期校验、自动保存、设置页布局、Linux 字体和发布流程问题。
- 将本轮 `CHANGELOG.md` 的 `Unreleased` 内容固化为 `v1.1.1`。
- 新增 tag 触发的 GitHub Release workflow，自动构建主 ZIP 和可选 OpenCV runtime ZIP 并带出 changelog。
- GitHub Release 资产使用 ASCII 文件名 `reimbursement-tool-vX.Y.Z-yyyymmdd.zip` 上传，避免 GitHub 规范化非 ASCII 资产名时剥掉中文；本地发布 ZIP 仍保持 `报销管理-vX.Y.Z-yyyymmdd.zip`。

本次不做：
- 不主动重新部署或验证 Linux 服务器；服务器验证记录仅保留本轮开发期间已完成结果。

## 版本号判断
- 发布为 v1.1.1。
- 判断依据：本轮以既有功能修复、体验打磨、文档和发布流程完善为主，不包含不兼容数据结构变化。
