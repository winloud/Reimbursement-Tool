# v1.4.1 发布计划

> 只记录当前目标、范围、验收条件和阻塞；完成结果、长期验证和技术决策分别写入 `CHANGELOG.md`、`docs/testing/`、`docs/decisions/`。正式发布前冻结本文件。

## 状态

- 版本号：v1.4.1
- 计划状态：内容已冻结
- 预计版本类型：patch

## 目标

- [x] 同一报销人的同一自然日只允许一张报销单占用，自动补贴天数只计算当前草稿实际取得的日期。
- [x] 已保存草稿的日期占用同步进入出差天数、月度趋势和出差负荷热力图。
- [x] 日期占用随保存、删除、恢复和数据导入稳定流转，不反向改写其他报销单。
- [x] 数据维护页优先呈现程序更新，并让更新、版本管理、备份恢复和诊断信息保持清晰层级。
- [x] ZIP 更新从选择、校验、确认到重启始终复用原位主操作，后台刷新不再卸载整页或打断焦点。

## 范围

- 本轮包含：新增报销日期占用表及 v7 数据迁移；按“报销人 + 日期”唯一占用；当前草稿保存时重新取得空闲日期；人工核定记录仍占用日期；编辑器重叠提示；看板按占用记录统计人天；完整数据包 v7、数据库完整性检查和旧包兼容。
- 本轮同时包含：数据维护页任务层级调整；程序更新原位主操作与行内确认；安装后静默刷新；备份、版本、暂存包和诊断信息的可见分组。
- 本轮不包含：自动把释放日期转给其他报销单；改变现有行程“起 / 止”区间规则；发布、打包或部署。

## 验收条件

- [x] 同一报销人下，7/18–7/19 的先保存报销单计算 2 天，后保存的 7/19–7/20 报销单计算 1 天；不同报销人互不占用。
- [x] 重新编辑当前草稿时不把自身日期视为冲突；删除会释放日期，其他草稿仅在下次保存时取得释放日期；恢复按当时空闲日期重新占用。
- [x] 人工核定、零日标准、跨月跨年、起止多区间、批量操作和并发保存均保持唯一占用与正确金额。
- [x] v6 数据库按报销单 ID 初始化占用并升级到 v7；v1–v7 数据包可导入，v7 可保留具体占用日期，完整性检查能识别无效占用。
- [x] 看板金额、单数、费用分布、出差人天、趋势和热力图全部包含已保存草稿，草稿金额归入待报销；相关前后端测试、生产构建和 `All` 验证通过。
- [x] 数据维护页按“程序更新 → 备份与恢复 → 诊断与检查”排列，所有管理信息保持展开，桌面和窄屏均无页面级水平溢出。
- [x] 兼容更新 ZIP 的选择、校验、安装确认使用同一主按钮位置；取消确认可恢复，异步期间不丢失焦点，安装完成后原位提供单击重启。
