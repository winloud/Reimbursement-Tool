# 途中补贴模式与输入框聚焦样式验证（2026-07-26）

> 本文只保留可长期复用的人工验证结论。原始效果图、实现截图和合并对照图属于本地审计产物，不是仓库依赖。

## 验证范围

- 视口：`1920 × 1080`、`874 × 695`、`390 × 844`。
- 状态：自动计算、人工核定 `¥80.00`、人工金额编辑、取消编辑、切回自动。
- 焦点：人工金额弹窗和基本信息输入框。

## 结论

- 最终结果：通过。
- 无 P0、P1 或 P2 视觉偏差。
- 桌面与移动端均无控件重叠或页面级水平溢出。
- 自动模式使用既有主色，人工模式使用警告色；模式切换即时生效且不弹窗。
- 人工模式的编辑图标位于金额旁，金额弹窗继续保留校验、取消、Enter 和保存行为。
- 聚焦输入框使用 2px 主色边框、白色浮动标签底色和加粗主色文字，不再显示缺口阴影。
- `874px` 与 `390px` 下浮动标签均完整可见。

## 已确认的实现约束

- 保留既有 360px 桌面汇总栏和 MUI 字体比例。
- 不新增位图、占位图标或自制图标。
- 保留项目字体、数字对齐、卡片间距和移动端密度。
- 开关和编辑按钮均有可访问名称或提示。

## 对应改动

- 将计算状态 chip 和独立调整按钮替换为自动/人工模式开关。
- 自动模式隐藏金额编辑入口；人工模式仅通过金额侧编辑图标打开金额编辑。
- 人工金额字段顶部间距调整为 12px，确保浮动标签位于可滚动内容内。
- 全局 outlined input 聚焦效果统一为无阴影的 2px 主色边框。
