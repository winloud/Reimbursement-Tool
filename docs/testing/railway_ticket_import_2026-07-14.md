# 铁路电子客票导入与中转识别测试依据

## 范围

- 铁路电子客票 PDF 的解析预览、字段修正和重复检测。
- 多票自动整理、手动顺序调整、默认中转合并、返程回环拆分和跨日提示。
- 行程与多张车船费发票的事务化创建及现有金额确认流程。

## 固定规则

- 正常中转在预览中默认选择合并，用户仍可取消或主动拆分。
- 不读取发车时间；相邻车票站点连续且日期为同日或次日时默认合并。
- 首次预览按日期和精确站点连接图整理车票；仅唯一简单路线自动重排，分叉、多前驱或循环保留该分量上传顺序，用户手动移动后不反复覆盖。
- 下一票到达已经访问过的站点时，在该票之前拆分为返程或路线回环。
- 站名仅做空格、大小写和末尾“站”的规范化精确匹配，不做模糊匹配。
- 站名主体与独立“站”后缀分属相邻文字运行时，仅在内容顺序相邻、基线接近且水平字符步进合理时拼接；不同字体、字号及 Form XObject 缩放不作为拒绝条件。
- 下一票到达任一已访问站点时按返程或路线回环处理，不与前序车票合并。
- 导入行程的出发、到达小时均保持为空。
- 预览批次内单个损坏或无法解析的 PDF 只跳过该文件并在预览中提示，不影响其余车票；全部无法解析时报错并清理临时令牌目录。
- 预览可删除单张车票，导入按预览车票子集校验，仅导入用户保留的车票；预览响应不再下发后端分组，分组由前端按实时交互计算。
