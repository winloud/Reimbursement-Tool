# 常规报销单模板验证（2026-08-11）

## 范围

- 以正式普通报销单空白扫描件为视觉依据重绘矢量底稿。
- 页面与出差报销单保持一致：`595×298 pt`，即约 `209.903×105.128 mm`。
- 程序模板不保留 Widget/AcroForm；独立人工填写版包含 75 个可编辑文本域。
- 矢量重绘脚本是 Windows 校准工具，重生成时使用系统楷体和黑体；程序运行时模板已嵌入所需字体，不依赖终端另行安装。
- 扫描对照必须使用原 PDF 可视页面的完整宽度，仅裁切顶部 `105.13 mm`；固化页面旋转后只允许平移裁切，不缩放、不重采样扫描图像。

## 数字验证

- 运行时矢量模板单独渲染通过：标题、表格线、四行明细、九位金额格、合计和审批/签名留白无裁切、重叠或模糊。
- AcroForm 回读通过：75 个字段、75 个 Widget，名称唯一，坐标全部在页面内，每个 Widget 均有非空 `/AP` `/N` 外观流。
- 正式人工填写版的 Widget 已设为透明、无边框；空白状态的渲染结果与无表单的程序模板一致，不会显示或打印校对框。
- 扫描对照版保留蓝色边框和浅蓝填充，仅用于辨认填表域范围，不作为正式输出外观。
- 旧版扫描对照曾裁掉原件四边并强制拉伸至 `595×298 pt`，因此基于该对照完成的矢量坐标验收结论作废。修正版保持扫描图像原始流不变，输出裁切页约为 `595.2×298.006 pt`（`209.973×105.13 mm`）。
- 原扫描 JPEG 在最终校对 PDF 中保持 `3507×2480`、`DCTDecode` 和原始流哈希不变；页面旋转固化为 `0`，裁切过程只应用平移和页面框，不发生解码、重采样或缩放。
- 300 DPI 原尺寸叠图中，29 条共同主网格中心线的长度加权偏差为：p50 `0.0887 mm`、p95 `0.1976 mm`、最大 `0.1976 mm`；校准过程未对扫描件做自动旋转、缩放或仿射对齐。
- 标题、记账凭证附件、右侧附件张数、Logo、表号和左侧品牌字样均已写回矢量生成脚本；品牌整体尺寸与中心已对齐扫描件，校对版默认不重复覆盖近似品牌元素，另用完整品牌叠图完成核验。
- 临时写入样例通过：日期、第一行明细、单据张数、金额位、大写合计和报销人可写入、回读并渲染。
- 程序实际输出样例通过：四行满载时中文明细与备注左对齐且保留左右间隙；金额最高位前一空格填入 `￥`，满九格金额保留全部数字；日期、附件数、大写金额与报销人均未越格，手签区域保持空白。
- 人民币大写跨四位分段用例已补齐，`1234573.89` 不再在“万”和“肆仟”之间错误插入“零”。
- PDF 生成与模板专项：`python -m pytest tests/test_regular_template_generator.py tests/test_pdf_generation.py -q`，42 项通过。
- 后端全量验证：`python -m pytest -q`，431 项通过、2 项跳过。
