# 常规报销单模板验证（2026-08-11）

## 范围

- 以正式普通报销单空白扫描件为视觉依据重绘矢量底稿。
- 页面与出差报销单保持一致：`595×298 pt`，即约 `209.903×105.128 mm`。
- 程序模板不保留 Widget/AcroForm；独立人工填写版包含 75 个可编辑文本域。
- 矢量重绘脚本是 Windows 校准工具，重生成时使用系统楷体和黑体；程序运行时模板已嵌入所需字体，不依赖终端另行安装。

## 数字验证

- 渲染检查通过：标题、表格线、四行明细、九位金额格、合计和审批/签名留白无裁切、重叠或模糊。
- AcroForm 回读通过：75 个字段、75 个 Widget，名称唯一，坐标全部在页面内，每个 Widget 均有非空 `/AP` `/N` 外观流。
- 正式人工填写版的 Widget 已设为透明、无边框；空白状态的渲染结果与无表单的程序模板一致，不会显示或打印校对框。
- 扫描对照版保留蓝色边框和浅蓝填充，仅用于辨认填表域范围，不作为正式输出外观。
- 已回读人工微调后的扫描对照版：年月日域上移，复核/出纳域右移，报销人姓名域和大写合计域缩窄并右移；随后按验收意见将四行“报销内容”和“备注”共 8 个 Widget 左右各额外内缩约 `1.5 mm`，其余字段坐标保持人工版结果。
- 人工调整的标题、记账凭证附件及右侧附件张数字号/位置已写回矢量生成脚本；校对版不重复叠加近似徽标和左侧厂商字样，正式矢量底稿仍保留这些品牌元素。
- 临时写入样例通过：日期、第一行明细、单据张数、金额位、大写合计和报销人可写入、回读并渲染。
- 程序实际输出样例通过：中文明细与备注左对齐且保留左右间隙；金额最高位前一空格填入 `￥`，满九格金额保留全部数字；日期、大写金额与报销人对齐到矢量底稿。
- 专项回归：`python -m pytest tests/test_pdf_generation.py -k regular -q`，10 项通过。
- 后端全量验证：`python -m pytest -q`，428 项通过、2 项跳过；发布工具 53 项通过。
